# 🔍 Linear Search – Interview Preparation (JavaScript)

---

# 📌 1. Searching in an Unsorted Array

## ❗ Key Point

You **cannot use Binary Search** because the array is not sorted.
So, we use **Linear Search**.

---

## 🧠 Problem

Find the index of a target element in an unsorted array.

### 🧩 Example

Input: `[2, 4, 5, 7, 9]`, target = `9`
Output: `4`

---

## ⚙️ Algorithm

1. Start from index `0`
2. Check each element one by one
3. If element equals target → return index
4. If not found → return `-1`

---

## 💻 Solution

```javascript
let arr = [2, 4, 5, 7, 9];
let target = 9;

function linearSearch(a, t) {
  for (let i = 0; i < a.length; i++) {
    if (a[i] === t) return i;
  }
  return -1;
}

console.log(linearSearch(arr, target));
```

---

## ⏱️ Complexity

* Time: **O(n)**
* Space: **O(1)**

# 📌 2. Find All Occurrences

## 🧠 Problem

Return all indices where the target appears.

### 🧩 Example

Input: `[1, 2, 3, 2, 4, 2]`, target = `2`
Output: `[1, 3, 5]`

---

## ⚙️ Algorithm

1. Traverse the array
2. If element equals target → store index
3. Return the result array

---

## 💻 Solution

```javascript
let arr2 = [2, 4, 5, 7, 8, 2, 4, 1, 9];
let target2 = 4;

function linearSearchWithOccurrences(a, t) {
  let result = [];
  
  for (let i = 0; i < a.length; i++) {
    if (a[i] === t) {
      result.push(i);
    }
  }
  
  return result;
}

console.log(linearSearchWithOccurrences(arr2, target2));
```

---

## ⏱️ Complexity

* Time: **O(n)**
* Space: **O(k)** (k = number of matches)

# 📌 3. Linear Search in String

## 🧠 Problem

Check if a character exists in a string.

### 🧩 Example

Input: `"hello"`, target = `"e"`
Output: `true`

---

## ⚙️ Algorithm

1. Loop through each character
2. If match found → return `true`
3. Else return `false`

---

## 💻 Solution

```javascript
let sample = "hello";

function checkCharacterExist(s, t) {
  for (let ch of s) {
    if (ch === t) return true;
  }
  return false;
}

console.log(checkCharacterExist(sample, "e"));
```

---

## ⏱️ Complexity

* Time: **O(n)**
* Space: **O(1)**

---

# 📌 4. Find Minimum Using Linear Search

## 🧠 Problem

Find the smallest element in an array.

### 🧩 Example

Input: `[5, 3, 8, 1, 4]`
Output: `1`

---

## ⚙️ Algorithm

1. Assume first element is minimum
2. Compare it with all elements
3. Update minimum if a smaller value is found

---

## 💻 Solution

```javascript
function findMin(arr) {
  let min = arr[0];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] < min) {
      min = arr[i];
    }
  }

  return min;
}
```

---

## ⏱️ Complexity

* Time: **O(n)**
* Space: **O(1)**

# 📌 5. Sentinel Linear Search (Interview Favorite)

## 🧠 Problem

Optimize linear search by reducing unnecessary comparisons.

---

## ❗ Problem in Normal Linear Search

Each iteration does:

1. Boundary check → `i < n`
2. Comparison → `arr[i] === target`

👉 This adds extra overhead.

---

## 💡 Idea (Sentinel Technique)

* Place the target at the last index temporarily
* Remove boundary check inside loop
* Loop will always stop

---

## ⚙️ Algorithm

1. Store last element
2. Replace last element with target
3. Loop until target is found
4. Restore last element
5. Check if target was originally present

---

## 💻 Solution

```javascript
function sentinelLinearSearch(arr, target) {
  let n = arr.length;
  let last = arr[n - 1];

  // Place sentinel
  arr[n - 1] = target;

  let i = 0;

  // Search without boundary check
  while (arr[i] !== target) {
    i++;
  }

  // Restore original last element
  arr[n - 1] = last;

  // Check if target was found in original array
  if (i < n - 1 || arr[n - 1] === target) {
    return i;
  }

  return -1;
}
```

---

## ⏱️ Complexity

* Time: **O(n)**
* Space: **O(1)**

---

## 🚀 Key Insight

* Normal Linear Search → **2 comparisons per iteration**
* Sentinel Search → **1 comparison per iteration**

👉 Reduces work inside loop → slight performance improvement

---

# 🎯 Final Interview Tips

* Linear search works on **unsorted arrays**
* Always mention:

  * Time complexity: **O(n)**
  * Space complexity: **O(1)**
* Optimization:

  * Sentinel technique
  * Use better algorithms if possible (Binary Search, Hashing)
